Evaluation Dimension Pure ANN Pure FIS Hybrid Neuro-Fuzzy Verdict
Key Academic Finding: While Pure ANN demonstrates high statistical pattern extraction, it lacks diagnostic transparency. Pure FIS provides transparent reasoning but cannot weight question contributions dynamically. The Hybrid Neuro-Fuzzy architecture achieves the highest boundary stability (86.0%), real-time inference (1.19 ms), and complete explainable clinical justification.
